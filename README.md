## Краткое описание работы
В ходе выполнения лабораторной работы были освоены механизмы обработки исключений в C# и базовые инструменты отладки кода в среде VS Code.

**Что было изучено и реализовано:**
1. **Конструкция try/catch/finally:** Реализована обработка критических ошибок ввода данных, деления на ноль и переполнения типов.
2. **Безопасные методы:** Написан метод `SafeParseInt`, возвращающий значение по умолчанию вместо аварийного завершения программы при ошибке формата.
3. **Иерархия и генерация исключений:** Изучена работа встроенных типов исключений (`FormatException`, `DivideByZeroException`, `IndexOutOfRangeException`, `NullReferenceException`), а также освоен ручной вызов ошибок через оператор `throw new`.
4. **Инструменты отладчика VS Code:** Освоена работа с точками останова (Breakpoints), пошаговым выполнением программ (`Step Over`/`Step Into`), а также отслеживанием состояния переменных с помощью панелей `VARIABLES` и `WATCH`.

## Главные выводы
1. **Обработка исключений повышает надежность:** Конструкция `try/catch/finally` позволяет программе корректно реагировать на непредвиденные действия пользователя или сбои во время выполнения (Runtime), предотвращая аварийное закрытие приложения.
2. **Порядок блоков catch имеет решающее значение:** Блоки `catch` обязательно должны идти от частных (конкретных типов вроде `FormatException`) к общим (`Exception`). Если поставить общий блок первым, специфичные обработчики никогда не выполнятся.
3. **Отладчик эффективнее ручного вывода:** Использование встроенного отладчика (breakpoints, step-by-step, watch) экономит время при поиске багов и логических ошибок, так как позволяет видеть полную картину состояния памяти приложения «вживую», избавляя от необходимости загромождать код вызовами `Console.WriteLine`.
